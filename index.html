THE WORKSHOP: THREE DEMOS

They connect. FACTORY builds swarms, CAGE runs them, LOOP improves them. Each is one self contained HTML file, and each has a recorded playback mode that needs no key.

DEMO 1 · BUILD
FACTORY
swarm factory

Describe a domain in plain language. A nine phase pipeline analyzes it, designs a roster of specialized agents, drafts each prompt, and reviews the result.

enter factory →
DEMO 2 · FIGHT
CAGE
red swarm vs blue swarm

Two swarms run a six phase adversarial exercise against each other. Same blue team, two different threat models, visibly different outcomes.

engage →
DEMO 3 · REFINE
LOOP
self improvement loop

Score the agents, rewrite the weakest one, design a new test, rerun. Import a CAGE result and close the loop on the agent that failed.

run a cycle →

THE WORKSHOP: THREE LABS

LAB 1 · FACTORY
About 30 minutes. Design a swarm for something you actually do.
LAB 2 · CAGE
About 45 minutes. Run both scenarios and compare what the blue team caught.
LAB 3 · LOOP
Stretch. Close the improvement loop on the agent that lost.

WHEN SOMETHING BREAKS

  • Run bin/doctor.sh. Every FAIL line carries a fix.
  • WORKSHOP-GUIDE.md lists the common error messages. It is also written to be pasted into a chat assistant before you ask it a question about this package.
  • docs/presenter-checklist.md has the in the room recovery order.
