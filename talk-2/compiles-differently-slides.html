Eight practices you can run yourself.

  1. The four questions, run on one control. You have already done it.
  2. Re-run and compare distributions, with n said out loud.
  3. The layered check. Fixtures test the aim you intended. Primary text tests whether that aim was the right one. Downstream use tests whether the class boundary is in the right place.
  4. Compare two outputs blind, in one call, so a harsh grader is harsh on both.
  5. Make the failure path report a parse failure rather than a number.
  6. Count the rounds out loud, and know that it is a practice.
  7. Test a gate against known-positive and known-negative fixtures before you trust it.
  8. Run a contrast, not a second control. It must not share the first one's premises.
